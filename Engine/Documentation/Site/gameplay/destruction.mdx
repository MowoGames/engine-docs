Mowo has two kinds of destructible. A **Destructible** prop breaks into pre-cut pieces, like Unreal's Chaos geometry collections. A **VoxelDestructible** solid is carved away a sphere at a time. Both are reflected components in the **Physics** category and need a collider and a rigid body on the entity.

## Fractured props

The `Destructible` component breaks its entity into pieces when hit hard enough. <Source symbol="DestructibleComponent" />

| Field | Effect |
| --- | --- |
| `pieceCount`, `seed` | How many pieces and which cut |
| `breakOnImpact`, `impactThreshold` | Break on a collision harder than the threshold |
| `scatterImpulse` | How hard the pieces fly apart |
| `pieceLifetime` | Seconds before pieces are removed |
| `cascadeLevels` | Pieces are themselves destructible, with half the pieces each level and a higher threshold |
| `requestBreak` | Set it to break the prop from code |
| `partialDamage`, `damageRadius` | A hit releases only the pieces near it; the rest stands as a remnant |
| `anchor`, `anchorMargin` | Which side holds the prop up; remnant pieces cut off from it fall |
| `replicateBreaks` | The server owns breaks and sends one small event; every client replays the same pieces from its own bake |

### Bake the fracture

Without a bake, the pieces are cut at break time on the game thread, which costs a frame hitch on a prop with many pieces. Click **Bake Fracture** in the component's Details section to store the cut as a `.fracture` asset, referenced by the **Fracture Bake** field. A bake also guarantees every networked peer gets the same pieces. <Source path="Engine/Source/Runtime/Destruction/Public/Destruction/FractureBake.h" />

Fracture methods are `Uniform`, `Clustered`, `Radial`, `Planar`, `Slice` and `Brick`; brick walls can be laid in stretcher, stack, English, header or Flemish bond. <Source path="Engine/Source/Runtime/Destruction/Public/Destruction/FractureMethods.h" />

### Break from code

`DestructionSystem` applies damage directly: `ApplyPointDamage(entity, point, radius, impulse)` for one prop, `ApplyDamageField(center, radius, impulse)` for an explosion. <Source symbol="DestructionSystem" />

## Voxel destruction

The `VoxelDestructible` component turns its entity's box, sphere or mesh collider into voxels of `voxelSize` when play begins. Damage carves a sphere of voxels out; the carved voxels fall as rubble chunks, and any part no longer connected to the floor (with `anchorFloor`) drops as a dynamic rigid body. <Source symbol="VoxelDestructibleComponent" />

| Field | Effect |
| --- | --- |
| `voxelSize` | Resolution |
| `anchorFloor` | Pieces touching the bottom layer stay put |
| `rubbleChunk` | Voxels per rubble chunk |
| `density` | Mass per voxel volume |
| `maxDebris`, `debrisLifetime` | Debris budget |

Apply damage with `MVoxelDestructionStatics::ApplyVoxelDamage(position, radius)` from Visual Scripting or C++. It takes effect on the next simulation tick. <Source symbol="MVoxelDestructionStatics" />
