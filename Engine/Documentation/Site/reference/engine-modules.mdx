The engine source has <Fact id="modules.length" /> modules. A module's group folder decides what may ship: a target that links a module its type rules out fails to build, so an editor module can never end up in a game. How modules depend on each other is described in [Architecture](/docs/programming/architecture/).

A module's dependencies use its short name (`"Core"`, `"EngineLoop"`). At run time an engine library is named `MowoEngine.<Name>`, the name plugin manifests and `FModuleManager` use; EngineLoop's binary is `MowoEngine`. MowoServer is the one module that declares a category of its own, `Server`.

Modules with no API link have no public headers: hosts, test targets, programs, and the RHI backends, whose headers are internal to the engine.

The feature modules (AINavigation, VoiceChat, Narrative, Destruction, GeometryTools, PointCloud, Sequencer, LevelGen, Accessibility, PCG, GpuEcs) are loaded by name at start-up rather than linked. Plugins under `Engine/Plugins/` are listed in [Writing a plugin](/docs/programming/plugins/).
