Mowo ships as an installed editor build: Mowo Editor, the Mowo Project Launcher, the build tool `mbt` and the headers and libraries a game's C++ module compiles against. You do not build the engine. You install it, sign in, and create projects.

## What you need

- **Windows 10 or 11, 64-bit.** The installed build is Windows-only for now.
- **A GPU with Direct3D 12 or Vulkan.** See [Platforms and graphics APIs](/docs/reference/platforms/).
- **A Mowo ID and the free Personal (Beta) license.** See [Sign in and activate your license](/docs/getting-started/sign-in-and-license/).
- **For C++ only: a clang toolchain.** Projects that use only Visual Scripting and content do not compile anything. A project with a C++ game module needs the toolchain described below.

## Install the editor

<Steps>
<Step title="Download">
Download the installer for the current release from the download page on mowoengine.com.
</Step>
<Step title="Run the installer">
The installer is a per-user MSI. It installs into `%LOCALAPPDATA%\Programs\MowoEditor` without an administrator prompt and adds **Mowo Project Launcher** and **Mowo Editor** to the Start Menu. A newer version upgrades the installed one in place.
</Step>
<Step title="Start the Project Launcher">
Open **Mowo Project Launcher** from the Start Menu, sign in on its **Account** page and activate the computer. Then create a project from a template ([Create a project](/docs/getting-started/create-a-project/)).
</Step>
</Steps>

<Screenshot id="getting-started-launcher-first-run" alt="Mowo Project Launcher on first start after installing: the sidebar with the Sign in row at the bottom, and the template wizard in the main area." />

Keep the per-user install location. Building a game module writes intermediate files under the install, which a read-only Program Files install would refuse.

## Install the C++ toolchain

A game module is compiled with clang against the Microsoft C++ runtime and the Windows SDK. Install:

| Component | Version | Where to get it |
| --- | --- | --- |
| LLVM (clang-cl, lld-link) | 20.1 or newer, 23 preferred | llvm.org, or the **C++ Clang tools for Windows** component of Visual Studio |
| MSVC toolset (the C++ runtime and STL) | 14.38 or newer | Visual Studio or the Build Tools, workload **Desktop development with C++** |
| Windows SDK | 10.0.22621.0 or newer | Same Visual Studio installer |

The minimum and preferred versions are read from `Engine/Config/Toolchains.ini` in the install <Source path="Engine/Config/Toolchains.ini" />. Set `LLVM_PATH` to point `mbt` at a specific LLVM. You do not need the .NET SDK: the `mbt` in the install is self-contained.

## Check your machine

Run `mbt doctor` from the install folder. It reports each toolchain component it found, its version against the pinned range, and what is missing:

```powershell
cd "$env:LOCALAPPDATA\Programs\MowoEditor"
./mbt.cmd doctor
```

## How mbt works in the installed build

The engine's modules come prebuilt, so `mbt` only compiles your project's modules:

- **Name your module.** `mbt build -t MyGame --extra-source D:/Projects/MyGame/Source` builds the `MyGame` module; a bare `mbt build` is refused.
- **The configuration is fixed.** A game module builds in the configuration the engine shipped as, because C runtime flavors cannot mix across the engine's DLLs. Another `-c` is corrected, with a log line.
- **Reflection code still generates.** The header tool runs inside `mbt` for every module that uses `MCLASS` and the other markup.

Most of the time you do not call `mbt` yourself: the editor compiles and hot-reloads the game module ([Working with C++](/docs/editor/working-with-cpp/)). [Your first build](/docs/getting-started/first-build/) walks through both ways.

## Troubleshooting

| Symptom | Fix |
| --- | --- |
| The editor refuses to start and offers the Project Launcher | This computer has no valid license lease. Sign in and activate it in the Project Launcher ([license](/docs/getting-started/sign-in-and-license/)). |
| `mbt doctor` reports no clang | Install LLVM, or set `LLVM_PATH` to its folder. |
| `mbt doctor` reports no MSVC toolset or Windows SDK | Add the **Desktop development with C++** workload in the Visual Studio installer. |
| A build fails with permission denied on a DLL | A running editor or game holds the file. Close it and build again. |
