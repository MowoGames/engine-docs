Content Examples is a sample project of small maps. Each map demonstrates one feature, so you can see how a thing is set up before you build your own. Open `Content/Maps/Hub.mmap`, the start map, and walk the plinths: each one names a room and the map to open. Or open any numbered map from the Content Browser and press Play. Every map is self-contained and spawns the same first-person explorer.

## Controls

| Input | Action |
|---|---|
| **W** **A** **S** **D** | Move |
| Mouse | Look |
| **Shift** / **Space** | Sprint / jump |
| **E** | Interact |
| **Esc** | Release the mouse |

## The rooms

| Map | Feature | What you see |
|---|---|---|
| `01_Materials` | Materials | Spheres sweeping roughness at zero and full metalness, a translucent cube and an emissive sphere |
| `02_Lights` | Lights | A point light, a shadowed spot, a rect light and a directional sun on the same props |
| `03_GlobalIllumination` | Global Illumination | A closed box with a red and a green wall and one lamp, so the bounce tints the white boxes |
| `04_Decals` | Decals | Decal projectors painting materials onto the floor and a wall |
| `05_AudioZones` | Audio zones | Two rooms with an ambience zone each and a door portal that muffles the far room when shut |
| `06_Animation` | Animation | One skeleton playing five clips, and a hero on the locomotion animation graph |
| `07_Physics` | Physics | A wall of dynamic boxes, spheres on a ramp and a stack |
| `08_Navigation` | Navigation | A nav mesh baked on load and two zombies that hunt the sound of your footsteps |
| `09_UI` | Arc and in-game UI | A menu and a player card mounted as in-game screens |
| `10_Networking` | Networking | Replicated crates: host with `--host-session`, join with `--connect <ip>` |
| `11_VisualScripting` | Visual Scripting | A door and a pickup, both Visual Script classes you can open and edit |

Each map has its title and a short explanation on the back wall, and a sign by the entrance that names the hub.

See [Templates](/docs/getting-started/templates/) for the starter projects the launcher offers.
