Mowo Engine is a C++ game engine with its own editor, build tool and data format. If you have used Unreal Engine 5, the shape is familiar on purpose: actors and worlds, reflection macros, a dockable editor, C#-scripted build rules and project templates all follow UE5. The one naming difference is the prefix for managed objects. Mowo writes `M` where Unreal writes `U`, so you use `MObject`, `MClass` and `MWorld`. The `F`, `A`, `I`, `T` and `E` prefixes mean what they mean in Unreal.

This section takes you from installing the editor to a saved level and a packaged build. Read the pages in order the first time.

<Callout type="warning">
Mowo is pre-1.0. This is version <Fact id="engine.version" />. The installed editor runs on Windows. See [Platforms and graphics APIs](/docs/reference/platforms/) for the current state of each platform.
</Callout>

## What you get

- **Mowo Editor** (`MowoEditor`), a dockable editor with play-in-editor, a content browser, a reflection-driven Details panel and asset editors.
- **Mowo Project Launcher** (`MowoProjectLauncher`), which lists your projects, creates new ones from templates and opens the editor.
- **MowoBuildTool** (`mbt`), the build tool that compiles your game's C++ modules against the prebuilt engine, cooks content and packages builds. The editor runs it for you; there is no CMake step.
- <Fact id="templates.length" /> project templates, from an empty Blank level to playable first-person, third-person, top-down, co-op, physics, horror, simulator and shooter starters.
- Rendering backends: <Fact id="rhiBackends" />. Direct3D 12 is the default on Windows, Metal on macOS.
- The player host `MowoGame` and the dedicated server `MowoServer`, which `mbt package` brands with your product name.

## What you need

| Requirement | Why |
|---|---|
| Windows 10 or 11 x64 | The platform the installed editor runs on |
| A GPU with Direct3D 12 or Vulkan | The editor renders with them |
| A Mowo ID | Signing in activates the free Personal (Beta) license |
| For C++ only: LLVM (clang-cl) and Visual Studio or Build Tools with the C++ workload | Your game module is compiled with clang against the MSVC libraries and the Windows SDK |

The toolchain versions are pinned in `Engine/Config/Toolchains.ini` in the install, and `mbt doctor` checks your machine against them. [Install Mowo](/docs/getting-started/installing/) covers each item.

## The path through this section

<Steps>
<Step title="Install the editor">
Run the installer, sign in in the Project Launcher and, for C++, install the toolchain. See [Install Mowo](/docs/getting-started/installing/).
</Step>
<Step title="Create a project">
Start from a template in the Project Launcher, or run `mbt init`. See [Create a project](/docs/getting-started/create-a-project/) and [Templates](/docs/getting-started/templates/).
</Step>
<Step title="Learn the project layout">
Know which folders you commit and which ones the engine regenerates. See [Project layout](/docs/getting-started/project-layout/).
</Step>
<Step title="Build your first level">
Place actors, save a `.mmap` level and press Play. See [Your first scene](/docs/getting-started/first-scene/).
</Step>
<Step title="Build code and package">
Compile your game module and produce a runnable folder with `mbt package`. See [Your first build](/docs/getting-started/first-build/).
</Step>
<Step title="Understand the model">
Read [Core concepts](/docs/getting-started/core-concepts/) for modules, objects, actors, the ECS, data files, visual scripting and UI.
</Step>
</Steps>
