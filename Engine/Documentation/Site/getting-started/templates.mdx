A template is a complete Mowo project under `Templates/TP_<Name>/`, beside the `Engine/` folder. Creating a project from one copies the folder and renames it after your project. The engine ships <Fact id="templates.length" /> of them. Each folder has a `README.md` with its controls and a tour of its content.

## The templates

Every template starts on `Content/Scenes/Main.mmap`. Every playable template's manifest starts on an engine game mode, so it plays before you build any C++. Its own game module carries a second game mode, the one you switch to once the module is built.

| Template | What you get | Starts with | Module game mode |
|---|---|---|---|
| Blank | An empty level with no actors and no code; Play lights it with the default sun, and the first C++ class you add creates the game module | none | none |
| [First Person](/docs/getting-started/template-first-person/) | A sci-fi apartment, corridor and lab under coloured accent lights, an animated body you see when you look down, a carryable crate, an item pickup and a sliding lab door driven by a Visual Scripting class | `AFirstPersonGameMode` | `AFirstPersonPlayerGameMode` |
| [Third Person](/docs/getting-started/template-third-person/) | A paved plaza ringed by brick buildings and streets, a clothed animated hero, a one-objective quest and a watchman on a daily schedule | `AThirdPersonGameMode` | `AThirdPersonPlayerGameMode` |
| [Horror](/docs/getting-started/template-horror/) (Solo and Co-op) | A dark facility lit by the survivors' flashlights, doors that open, a stalker that hunts by sound and a fail state when it catches you | `AFirstPersonGameMode` | `AHorrorGameMode` |
| [Top Down](/docs/getting-started/template-top-down/) | A walled yard under a fixed camera, five crates to collect and zombies that hunt by sound | `BP_TopDownGameMode` | none |
| [Vehicle](/docs/getting-started/template-vehicle/) | A race car on the vehicle component, a circuit with checkpoints, a lap timer and three cameras | `BP_RaceGameMode` | none |
| [2D Platformer](/docs/getting-started/template-platformer-2d/) | A side-scroller on Kenney art: an auto-tiled tilemap level with platforms, coins, patrolling slimes, a goal flag and a following camera | `BP_Platformer2DGameMode` | none |

The [Content Examples](/docs/getting-started/content-examples/) sample is not a template: it is one small map per engine feature, for reading rather than for starting a game from.

The launcher lists the Blank category first, then the others in the order of their `SortKey`, and labels every one except Blank **Playable**. Blank is the card selected when the wizard opens. It also tags a template with **Visual Scripting**, **Animation graph**, **Quests** or **AIGG (Arc In-Game Graphics)** when its content holds such assets.

## Controls

The first-person and third-person sets share their bindings. Each template's `Config/Input.ini` and `Content/Input/` assets hold them.

| Input | First Person, Horror Co-op, Simulator, Shooter | Third Person, Co-op, Physics Playground | Top-Down |
|---|---|---|---|
| <Kbd>W</Kbd> <Kbd>A</Kbd> <Kbd>S</Kbd> <Kbd>D</Kbd> | Move | Move, camera-relative |
| Mouse | Look | Orbit the follow camera |
| <Kbd>Space</Kbd> | Jump | Jump |
| <Kbd>Left Ctrl</Kbd> / <Kbd>Left Shift</Kbd> | Crouch / sprint | Crouch / sprint |
| <Kbd>E</Kbd> | Interact, pick up, drop | Interact, pick up, drop |
| <Kbd>Q</Kbd> | Throw what you carry | Throw what you carry |

In Horror Co-op, the right mouse button also throws.

## Variants

A template can offer variants of itself, the way the Unreal Engine templates do. When the template you pick has them, the wizard shows a **Variant** drop-down under the preview, and the summary names the choice. A variant keeps its own files in a folder that the other variants leave behind, and may start on its own map and game mode and switch on the plugins it needs.

| Template | Variants |
|---|---|
| First Person | **Walking sim** (no weapon) and **Shooter**: a service pistol on a stand, fired with the left mouse button, and target barrels in the lab, on the Combat plugin |
| Third Person | **Explore** (the plaza and its quest with the male hero), **Explore (female hero)** (the same map with the female hero) and **Melee combat**: a sword to pick up with <Kbd>E</Kbd>, combos on the left mouse button, block and parry on the right, and target dummies, all on the Combat plugin |
| Horror | **Solo** (one survivor and the stalker) and **Co-op (2 to 4 players)** (four survivor spawns, registered with the network session) |

## The module's game mode

A C++ template starts on the engine's stock game mode, so the project plays before anything is compiled. The template's module subclasses it: for example, the First Person module adds `AFirstPersonPlayer`, whose camera drops while crouched, and the Horror Co-op module adds `AHorrorPlayer`, which carries the flashlight.

The first time the editor opens a new C++ project it builds the game module for you and, once the module has loaded, sets **Game Mode Class** to the template's own mode, so the first Play already runs the template. If the build fails, the project keeps the stock mode and the Message Log says why. Then fix the errors, choose **Build › Compile Game Module**, and set **Game Mode Class** to the template's module game mode in **Edit › Project Settings… › Maps & Modes**. See [Your first build](/docs/getting-started/first-build/).

<Callout type="note">
Horror needs no build at all: it enables the HorrorKit plugin and names `AHorrorGameMode` in its manifest.
</Callout>

## Host and join a co-op session

Horror Co-op runs as a listen server. Start the host and the clients with the player host and your project's manifest:

```powershell
MowoGame.exe --project MyGame.mproject --host-session --port 7777
MowoGame.exe --project MyGame.mproject --connect <host-ip> --port 7777
```

In the editor, the Play menu's **Play As Client** runs several clients for you. See [Multiplayer](/docs/multiplayer/).

## What is not finished

The template READMEs list their open seams. The one you notice first:

- **Horror**: the first-person hand holds no torch prop, and the stalker hears noise but does not investigate its source before it hunts.

## How a template is described

`Config/TemplateDefs.ini` tells the launcher how to present the template and how a copy becomes your project. It is read by `FTemplateDefs`, under the section `[/Script/AssetSystem.TemplateProjectDefs]`:

```ini title="Templates/TP_FirstPerson/Config/TemplateDefs.ini"
[/Script/AssetSystem.TemplateProjectDefs]
Category=Games
DisplayName="First Person"
Subtitle="Camera, input, interaction"
Description="A ready-to-play first-person starter: ..."
Icon=crosshair
SortKey=10
bPlayable=True
bAllowProjectCreation=True
ModuleGameModeClass=AFirstPersonPlayerGameMode
+FoldersToIgnore=Binaries
+FoldersToIgnore=Build
+FoldersToIgnore=Intermediate
+FoldersToIgnore=Saved
+FoldersToIgnore=Media
+FilesToIgnore="%TEMPLATENAME%.mproject"
+FilesToIgnore="Config/TemplateDefs.ini"
+FolderRenames=(From="Source/%TEMPLATENAME%",To="Source/%PROJECTNAME%")
+FolderRenames=(From="Source/%PROJECTNAME%/Public/%TEMPLATENAME%",To="Source/%PROJECTNAME%/Public/%PROJECTNAME%")
+FilenameReplacements=(Extensions=("cs","cpp","h"),From="%TEMPLATENAME%",To="%PROJECTNAME%",bCaseSensitive=True)
+ReplacementsInFiles=(Extensions=("cs","cpp","h","md"),From="%TEMPLATENAME%",To="%PROJECTNAME%",bCaseSensitive=True)
```

| Key | Meaning |
|---|---|
| `Category` | Launcher grouping, `Games` by default. The wizard lists the cards under their category: Blank, then Games, 2D, Multiplayer and any other |
| `+Variants` | `(Name, DisplayName, Description, Preview, StartScene, GameModeClass, ModuleGameModeClass, FoldersToIgnore, Plugins)`: one row per variant, the first is the default. `FoldersToIgnore` names the folders of the other variants, `Plugins` lists plugins to enable in `Config/Plugins.ini`, `Preview` a file in `Media/` |
| `+HiddenOptions` | Wizard options the template has no use for: `StarterContent`, `Platforms`, `Backend` or `Quality` |
| `DisplayName`, `Subtitle`, `Description` | The card and preview text |
| `Icon` | A Lucide icon id, drawn when `Media/` has no image |
| `SortKey` | Order in the launcher, low first (default 1000) |
| `bPlayable` | Adds the **Playable** tag |
| `Language` | `Cpp` or `VisualScripting`: the wizard's language filter. Without it a template with `Source/` is C++ and any other is Visual Scripting |
| `bAllowProjectCreation` | `False` hides the template from the launcher |
| `ModuleGameModeClass` | The module's own game mode, the one to switch to after building |
| `+Tags` | Extra tags for the preview |
| `+FoldersToIgnore`, `+FilesToIgnore` | What stays behind when the folder is copied |
| `+FolderRenames` | Folders that move, such as `Source/TP_FirstPerson` to `Source/<Project>` |
| `+FilenameReplacements` | Text replaced in file names with the listed extensions |
| `+ReplacementsInFiles` | Text replaced inside files with the listed extensions |

`%TEMPLATENAME%` is the template folder's name and `%PROJECTNAME%` the new project's; both also come as `_UPPERCASE` and `_LOWERCASE` forms. A file already at the destination is kept, never overwritten. A template with `Source/` needs a project name that is a C++ identifier, because it becomes the module and target names <Source path="Engine/Source/Runtime/AssetSystem/Public/Project/TemplateDefs.h" />.

The new project's start scene and starting game mode come from the template's own `TP_<Name>.mproject`. `Media/TP_<Name>.png` is the card icon and `Media/TP_<Name>_Preview.png` the preview image. The preview is a real capture of the template's start scene on Direct3D 12, 16:9 and under 600 KB (palette PNG): the `template-media-capture-*` rows take it from the editor's default viewport camera at 1280 by 720, and a better-framed shot can be dropped in over it. The launcher draws it in a 16:9 well, so keep that aspect when you replace it with your own. `template-matrix-test` fails for a preview under 20 KB, off 16:9, or nearly flat.

### Add your own template

Copy a template folder to `Templates/TP_<YourName>/`, rename its `.mproject`, `Source/TP_<Name>/` and target files to match, and edit `Config/TemplateDefs.ini`. The launcher lists every folder under `Templates/` whose `Config/TemplateDefs.ini` allows project creation, so it appears the next time the launcher starts.
