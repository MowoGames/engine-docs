A template is a complete Mowo project under `Templates/TP_<Name>/`, beside the `Engine/` folder. Creating a project from one copies the folder and renames it after your project. The engine ships <Fact id="templates.length" /> of them. Each folder has a `README.md` with its controls and a tour of its content.

## The templates

Every template starts on `Content/Scenes/Main.mmap`. Every playable template's manifest starts on an engine game mode, so it plays before you build any C++. Its own game module carries a second game mode, the one you switch to once the module is built.

| Template | What you get | Starts with | Module game mode |
|---|---|---|---|
| Blank | An empty world: a floor and a sun, no code | none | none |
| First Person | A lit room, a carryable crate, an item pickup and a sliding door driven by a Visual Scripting class | `AFirstPersonGameMode` | `AFirstPersonPlayerGameMode` |
| Third Person | A lit arena, an animated SampleBiped, a one-objective quest and an NPC on a daily schedule | `AThirdPersonGameMode` | `AThirdPersonPlayerGameMode` |
| Top-Down | A walled arena under a steep follow camera, world-relative movement and a shrine you can use | `ATopDownGameMode` | `ATopDownPlayerGameMode` |
| Multiplayer Co-op | A listen server: one player hosts, others join, each gets a replicated third-person character | `AThirdPersonGameMode` | `ACoopGameMode` |
| Physics Playground | Stacks of simulated crates on a launch plate, a bouncy and a heavy ball, a ramp | `AThirdPersonGameMode` | `APhysicsPlaygroundGameMode` |
| Horror Co-op | A dark facility lit by the players' flashlights, a checkpoint and a wandering stalker that can hear you | `AFirstPersonGameMode` | `AHorrorGameMode` |
| Simulator | A small shop: carryable stock, a register, a customer on a schedule and a till HUD | `AFirstPersonGameMode` | `ASimulatorGameMode` |
| Shooter | A firing range: a hitscan rifle, a projectile launcher, target dummies and ammo crates | `AFirstPersonGameMode` | `AShooterGameMode` |

The launcher shows them in that order (by `SortKey`) and labels every one except Blank **Playable**. It also tags a template with **Visual Scripting**, **Animation graph**, **Quests** or **ArcUI** when its content holds such assets <Source path="Engine/Source/Editor/MowoProjectLauncher/Private/Model/LauncherTemplates.cpp" />.

## Controls

The first-person and third-person sets share their bindings. Each template's `Config/Input.ini` and `Content/Input/` assets hold them.

| Input | First Person, Horror Co-op, Simulator, Shooter | Third Person, Co-op, Physics Playground | Top-Down |
|---|---|---|---|
| <Kbd>W</Kbd> <Kbd>A</Kbd> <Kbd>S</Kbd> <Kbd>D</Kbd> | Move | Move, camera-relative | Move, world-relative |
| Mouse | Look | Orbit the follow camera | |
| <Kbd>Space</Kbd> | Jump | Jump | Jump |
| <Kbd>Left Ctrl</Kbd> / <Kbd>Left Shift</Kbd> | Crouch / sprint | Crouch / sprint | |
| <Kbd>E</Kbd> | Interact, pick up, drop | Interact, pick up, drop | Interact |
| <Kbd>Q</Kbd> | Throw what you carry | Throw what you carry | |

The Shooter replaces throwing with weapons: left mouse fires (hold for full auto on the rifle) and <Kbd>R</Kbd> reloads. In the Simulator and Horror Co-op, the right mouse button also throws.

## Switch to the module's game mode

The engine game modes give you the stock pawn. The template's module subclasses it: for example, the First Person module adds `AFirstPersonPlayer`, whose camera drops while crouched, and the Horror Co-op module adds `AHorrorPlayer`, which carries the flashlight.

<Steps>
<Step title="Build the module">
In the editor, choose **Build › Compile Game Module**. See [Your first build](/docs/getting-started/first-build/).
</Step>
<Step title="Set the game mode">
Open **Edit › Project Settings…**, go to **Maps & Modes** and set **Game Mode Class** to the template's module game mode from the table above.
</Step>
</Steps>

<Callout type="note">
In Horror Co-op, the stock first-person pawn has no flashlight, and the level has no directional light. Build the module and switch to `AHorrorGameMode` before you judge the lighting.
</Callout>

## Host and join a co-op session

Multiplayer Co-op and Horror Co-op run as a listen server. Start the host and the clients with the player host and your project's manifest <Source path="Engine/Source/Runtime/GameHost/Private/MGameEngine.cpp" />:

```powershell
MowoGame.exe --project MyGame.mproject --host-session --port 7777
MowoGame.exe --project MyGame.mproject --connect <host-ip> --port 7777
```

In the editor, the Play menu's **Play As Client** runs several clients for you. See [Multiplayer](/docs/multiplayer/).

## What is not finished

The template READMEs list their open seams. The ones you notice first:

- **Shooter**: the arena has no music, and the dummies count their kills but nothing shows a score.
- **Simulator**: the till amount is a HUD binding that **Open Shift** sets through a Visual Scripting graph. Nothing earns money yet.
- **Horror Co-op**: the stalker wanders on a schedule. It hears noise but does not investigate it, and the far-door stinger sound has no trigger.

## How a template is described

`Config/TemplateDefs.ini` tells the launcher how to present the template and how a copy becomes your project. It is read by `FTemplateDefs` <Source symbol="FTemplateDefs" />, under the section `[/Script/AssetSystem.TemplateProjectDefs]`:

```ini title="Templates/TP_FirstPerson/Config/TemplateDefs.ini"
[/Script/AssetSystem.TemplateProjectDefs]
Category=Games
DisplayName="First Person"
Subtitle="Camera, input, interaction"
Description="A ready-to-play first-person starter: ..."
Icon=crosshair
SortKey=10
bPlayable=True
bAllowProjectCreation=True
ModuleGameModeClass=AFirstPersonPlayerGameMode
+FoldersToIgnore=Binaries
+FoldersToIgnore=Build
+FoldersToIgnore=Intermediate
+FoldersToIgnore=Saved
+FoldersToIgnore=Media
+FilesToIgnore="%TEMPLATENAME%.mproject"
+FilesToIgnore="Config/TemplateDefs.ini"
+FolderRenames=(From="Source/%TEMPLATENAME%",To="Source/%PROJECTNAME%")
+FolderRenames=(From="Source/%PROJECTNAME%/Public/%TEMPLATENAME%",To="Source/%PROJECTNAME%/Public/%PROJECTNAME%")
+FilenameReplacements=(Extensions=("cs","cpp","h"),From="%TEMPLATENAME%",To="%PROJECTNAME%",bCaseSensitive=True)
+ReplacementsInFiles=(Extensions=("cs","cpp","h","md"),From="%TEMPLATENAME%",To="%PROJECTNAME%",bCaseSensitive=True)
```

| Key | Meaning |
|---|---|
| `Category` | Launcher grouping, `Games` by default |
| `DisplayName`, `Subtitle`, `Description` | The card and preview text |
| `Icon` | A Lucide icon id, drawn when `Media/` has no image |
| `SortKey` | Order in the launcher, low first (default 1000) |
| `bPlayable` | Adds the **Playable** tag |
| `bAllowProjectCreation` | `False` hides the template from the launcher |
| `ModuleGameModeClass` | The module's own game mode, the one to switch to after building |
| `+Tags` | Extra tags for the preview |
| `+FoldersToIgnore`, `+FilesToIgnore` | What stays behind when the folder is copied |
| `+FolderRenames` | Folders that move, such as `Source/TP_FirstPerson` to `Source/<Project>` |
| `+FilenameReplacements` | Text replaced in file names with the listed extensions |
| `+ReplacementsInFiles` | Text replaced inside files with the listed extensions |

`%TEMPLATENAME%` is the template folder's name and `%PROJECTNAME%` the new project's; both also come as `_UPPERCASE` and `_LOWERCASE` forms. A file already at the destination is kept, never overwritten. A template with `Source/` needs a project name that is a C++ identifier, because it becomes the module and target names <Source path="Engine/Source/Runtime/AssetSystem/Public/Project/TemplateDefs.h" />.

The new project's start scene and starting game mode come from the template's own `TP_<Name>.mproject` <Source path="Engine/Source/Runtime/AssetSystem/Private/ProjectSerializer.cpp" />. `Media/TP_<Name>.png` is the card icon and `Media/TP_<Name>_Preview.png` the preview image.

### Add your own template

Copy a template folder to `Templates/TP_<YourName>/`, rename its `.mproject`, `Source/TP_<Name>/` and target files to match, and edit `Config/TemplateDefs.ini`. The launcher lists every folder under `Templates/` whose `Config/TemplateDefs.ini` allows project creation, so it appears the next time the launcher starts.
