Mowo Editor is the desktop application you use to build a game: place actors in a level, author assets, play the game in place and package it. It is built on Arc, the engine's own UI framework, so every panel, menu and asset editor is drawn by the engine itself, with the same renderer your game uses. This section covers every part of it.

## Opening a project

The editor always works on one project: a folder with a `.mproject` file. Open it from the Mowo Project Launcher, which lists your projects and creates new ones from templates, or start the editor directly <Source path="Engine/Source/Editor/MowoEditor/Private/MowoEditor.cpp" />:

```powershell
& ".\MowoEditor.exe" --project D:\Games\MyGame\MyGame.mproject
```

| Option | Effect |
| --- | --- |
| `--project <path>` | The project to open |
| `--scene <path>` | The level to open, overriding the startup preference |
| `--no-splash` | Skip the splash screen |
| `--no-user-config` | Ignore your per-user configuration and preferences <Source path="Engine/Source/Editor/MowoEditor/Private/Settings/EditorPreferences.cpp" /> |

The editor UI is in English. See [Getting started](/docs/getting-started/) to install the engine and create your first project.

## How work flows through the editor

Most editing follows the same loop: you pick something, change it, and the change goes through one transaction system so it can be undone, saved and replayed.

<Flow steps={["Select in viewport or Outliner", "Edit in Details or an asset editor", "Transaction recorded (undoable)", "Document marked unsaved", "Save or autosave"]} highlight={2} caption="Every edit is one undo entry on the document it belongs to, and marks that document unsaved." />

- Each level and each asset document has its own undo history <Source path="Engine/Source/Editor/MowoEditor/Private/Core/EditorTransaction.h" />. <Kbd>Ctrl+Z</Kbd> and <Kbd>Ctrl+Y</Kbd> act on whichever one you are working in.
- An unsaved document shows a dot on its tab. <Kbd>Ctrl+S</Kbd> saves it and <Kbd>Ctrl+Shift+Alt+S</Kbd> saves everything. Autosave keeps copies for crash recovery.
- <Kbd>F5</Kbd> plays the level in a copy, so stopping leaves the level as it was, with your play-time tweaks kept.
- <Kbd>Ctrl+K</Kbd> opens the command palette, which finds actors, assets, commands and settings.
